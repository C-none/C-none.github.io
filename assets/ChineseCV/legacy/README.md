# Legacy sources

This directory contains the handwritten TeX resume sources that predate the bilingual YAML pipeline:

- `lhzy_resume_legacy_zh.tex`: the final handwritten Chinese source, including the NetEase experience.
- `cv_en_legacy.tex`: the former independent English source.

They remain available as historical references only. Neither file is build input; `../resume.yml` is the sole content source for published resumes.
